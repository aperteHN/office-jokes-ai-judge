A tiny Node program that writes one joke about office life to /output/entry.txt, byte for byte the same on every run, for the AI judge to rate head to head against the other entries.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
